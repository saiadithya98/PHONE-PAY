

# 📊 PhonePe Transaction Analytics Dashboard

**Interactive data analytics dashboard analyzing PhonePe digital payment transactions across multiple services using Power BI.**

---

## 🔹 Project Summary

Built an end-to-end **Power BI dashboard** to analyze **transaction volume, payment success rate, failure reasons, and monthly trends** across PhonePe services including **Insurance, Loans, Money Transfer, and Recharge & Bills**.

---

## 🔹 Key Highlights

* Analyzed **millions of transactions** using KPIs and visual analytics
* Achieved **95%+ success rate insights** across services
* Identified top failure reasons: **Wrong PIN, Server Error, Insufficient Balance**
* Designed **multi-page interactive dashboards** with filters and slicers

---

## 🔹 Dashboards Included

* Overall Transaction Overview
* Insurance Analytics
* Loan Services Analytics
* Money Transfer Analytics
* Recharge & Bill Payments Analytics

---

## 🔹 Tools & Skills Used

* **Power BI**
* **DAX Measures & Calculations**
* **Data Cleaning & Transformation**
* **Data Visualization & Dashboard Design**

---

## 🔹 Key Business Insights

* Loan and Insurance services generate the **highest transaction value**
* Failure rates remain under **5%**, indicating system reliability
* Monthly trends reveal **seasonal transaction patterns**
